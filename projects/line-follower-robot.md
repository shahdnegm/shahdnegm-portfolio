# Arduino Line-Following Robot — Custom PCB and Hardware Prototype

**Hands-on mechatronics / embedded systems project**

## Project overview

Built an educational mobile robot platform using an **Arduino Nano**, a **motor-driver module**, **DC geared motors**, and a front-mounted **IR line-tracking sensor array**. The project demonstrates the combination of mechanical assembly, electronics and embedded control required for a line-following robot.

## What the prototype photographs show

1. **Assembled hardware:** An Arduino Nano, wired motor driver, motor and wheel assembly, rechargeable battery pack, and illuminated multi-channel infrared tracking sensor board installed on a blue robot chassis. These photographs demonstrate physical assembly and integration; a moving or successful line-following run is not independently documented here.
2. **Custom PCB:** A black, shaped printed circuit board with footprints and routing for the controller and peripheral connections. The PCB includes visible project/contributor markings, so its design should be credited as collaborative unless individual responsibilities are confirmed.

## Engineering topics

- Microcontroller integration and electrical interconnections
- Motor-drive wiring and DC motor actuation
- Reflective infrared sensor input for line detection
- PCB prototyping and board layout
- Hardware assembly, troubleshooting and iterative prototyping
